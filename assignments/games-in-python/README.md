
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build the classic word-guessing game using Python strings, loops, and user input. You'll practice string manipulation, conditionals, and random selection while creating an interactive game where players guess letters to reveal a hidden word.

## 📝 Tasks

### 🛠️ Build a Hangman Game

#### Description
Create a Hangman game where players guess letters to reveal a hidden word before running out of attempts. The game should randomly select words, track guesses, and provide clear feedback on game progress.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses and show current progress (using underscores for unrevealed letters)
- Track incorrect guesses remaining and display them
- End the game when the word is guessed or attempts are exhausted
- Display clear win/lose messages with the final word revealed
